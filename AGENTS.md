# Правила работы

## 🔴 Пуш — только по явному разрешению

Не коммитить и не пушить каждую правку. Сначала накопить изменения локально,
проверить их вместе и показать результат. Затем **ждать явного** «пуш» /
«залей» / «коммить».

Разрешение на прошлый пуш не действует на следующий. Если сомневаюсь —
спрашиваю.

## Порядок

1. Правки локально.
2. `npm.cmd run typecheck`, `npm.cmd test`, `npm.cmd run build`.
3. Показать diff и результаты проверок.
4. Дождаться разрешения.
5. Один коммит на весь батч и `git push origin main`.

## Тесты и пользовательские процессы

- Никогда не завершать процессы `PathOfExileSteam.exe` / `PathOfExile*.exe` — это игра пользователя.
- Для тестов использовать mock-процесс с уникальным именем, например `CraftOverlayMockGame.exe`.
- Очищать только собственные процессы по pid/точному пути; не применять широкий `Stop-Process` по имени игры.
- Перед kill проверить, что процесс создан этим тестом.

## Git

- Ветка `main`; force-push и переписывание истории — только по отдельному разрешению.
- Не коммитить `release/`, exe и сгенерированные артефакты.
- Не коммитить секреты и локальные настройки.
- GitHub Release — только по явному разрешению.
