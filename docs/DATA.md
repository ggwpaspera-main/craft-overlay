# Справочные данные проекта

Два набора данных, которые понадобятся парсеру, оверлею и будущему крафт/трейд-функционалу.

- [`data/bases.json`](../data/bases.json) — базовые типы предметов PoE2 (RU), собранные с poe2db.
- [`data/currency.json`](../data/currency.json) — валюта PoE2 и её эффекты, взятые из соседнего проекта `default-workspace`.

Оба файла — **снимки** на 2026-11-05, а не живой API. При обновлении игры их нужно перегенерировать.

---

## 1. `data/bases.json`

Источник: <https://poe2db.tw/ru/>, страницы классов предметов (`/ru/One_Hand_Swords`, `/ru/Body_Armours`, …).
Собрано: 2026-11-05.

| Параметр | Значение |
|---|---|
| Классов | 36 |
| Базовых типов | 1881 |
| Категории | `weapon`, `offhand`, `armour`, `jewellery`, `flask`, `charm`, `jewel`, `waystone`, `tablet`, `relic`, `trap` |
| Иконки | URL на CDN poe2db (не копировались в репозиторий) |

Схема:

```jsonc
{
  "source": "https://poe2db.tw/ru/",
  "license": "PoE2DB content: CC BY-NC-SA 3.0",
  "updatedAt": "2026-11-05",
  "classes": [
    {
      "slug": "One_Hand_Swords",
      "name": "Одноручные мечи",
      "category": "weapon",
      "subtype": "oneHandSword",
      "url": "https://poe2db.tw/ru/One_Hand_Swords",
      "baseCount": 16,
      "bases": [
        {
          "slug": "Golden_Blade",
          "name": "Золотой клинок",
          "icon": "https://cdn.poe2db.tw/image/...",
          "properties": [
            { "label": "Физический урон", "value": "3-28" },
            { "label": "Шанс крит. попадания", "value": "5%" }
          ],
          "requirements": ["Уровень 20", "7 Сила", "7 Ловк.", "7 Инт."],
          "implicitMods": ["+(16—24) ко всем характеристикам"],
          "explicitMods": []
        }
      ]
    }
  ]
}
```

Особенности и ограничения:

- **Одинаковые `slug` с разными именами/статами сохраняются** (например, `Ascetic_Garb` встречается как «Одеяние аскета» и «Наряд аскета»). Это разные базы в данных poe2db; дубликаты с полностью совпадающими полями отброшены.
- У `Tablets` на poe2db нет базовых типов (`baseCount: 0`) — только уникальные плитки; класс оставлен для полноты.
- Часть подписей может остаться английской (`Base Movement Speed`), а у некоторых баз в самом источнике нет значений (например, `Energy_Blade` — «Добавляет от до урона от молнии»).
- `properties` — массив `{label, value}` в порядке страницы; `requirements` — разбитые по запятой строки.
- `Traps`, `Talismans`, `Relics` выделены в отдельные категории, которых пока нет в `ItemCategory` парсера. При интеграции нужно будет либо расширить тип, либо замапить.

Лицензия источника: в футере poe2db указано **CC BY-NC-SA 3.0**. При публичном использовании данных нужна атрибуция и соблюдение условий; для коммерческого использования — отдельно проверять.

## 2. `data/currency.json`

Источник: `default-workspace/poe2-craft-guide/orbs.html` (данные соседнего проекта).
Собрано: 2026-11-05.

| Параметр | Значение |
|---|---|
| Всего записей | 145 |
| Основных сфер (`core: true`) | 11 |
| С описанием | 11 |
| Иконки | относительные пути из соседнего проекта, в репозиторий не копировались |

Схема:

```jsonc
{
  "source": "default-workspace/poe2-craft-guide/orbs.html",
  "updatedAt": "2026-11-05",
  "coreCount": 11,
  "items": [
    {
      "name": "Сфера хаоса",
      "en": "Chaos Orb",
      "effect": "Убирает 1 случайный мод и добавляет 1 новый...",
      "description": "Убирает 1 случайный мод и добавляет 1 новый...",
      "icon": "images/chaos.webp",
      "core": true
    }
  ]
}
```

- `core: true` — 11 основных сфер, у которых есть расширенное описание из карточек `orbs.html`.
- `effect` — краткий эффект; `description` — расширенное описание (для core).
- `en` заполнен там, где удалось найти соответствие в `_ru_map.json` / `ru-names.json`.
- Часть валюты имеет пустой `effect` — так было в исходном HTML (например, знаки/руды).

## 3. Как обновлять

1. **Базы:** перегенерировать запросы к `https://poe2db.tw/ru/<ClassSlug>` и распарсить карточки `a.whiteitem` (свойства, требования, имплициты). Скрипт пока не закоммичен; при необходимости добавлю `tools/`.
2. **Валюта:** обновить `orbs.html` в соседнем проекте и пересобрать `data/currency.json` (11 карточек `.orb-card` + 134 `.curr`).

Источник `default-workspace` — **read-only**: его можно читать и копировать, но нельзя редактировать.
