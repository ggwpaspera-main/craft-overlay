# Крафт-советник (пробный режим)

M6 заменён: **без trade API и цен**. Задача — по тексту предмета подсказать новичку, что с ним делать дальше.

Текущий скоуп: **нательные доспехи на чистом энергощите**, редкости normal / magic / rare.
Для остальных слотов и гибридных баз советник пока честно пишет «не поддерживается».

## Откуда правила

- Список целевых модов — из гайда-соседа `poe2-craft-guide/bases.html` («Лучшие статы для волшебного предмета»), адаптированный под чистый ЭЩ.
- База модов, тиры и веса — `data/reference/mods-data.json` (54 класса).
- Базы и их свойства — `data/bases.json`.
- Валюта и эффекты — `data/currency.json`.

## Как оценивается предмет

1. Проверка: это нательный доспех, в тексте есть ЭЩ, нет брони/уклонения (пока только чистый ЭЩ).
2. Явные моды (explicit) раскладываются на префиксы/суффиксы.
3. Каждый мод классифицируется:
   - **хороший** — целевой для ЭЩ-брони;
   - **нейтральный** — полезный, но не ключевой;
   - **мусор** — слабый для ЭЩ-брони.
4. Считаются открытые слоты (magic: 1P+1S, rare: 3P+3S).
5. Выдаётся совет по редкости.

### Целевые префиксы

- % повышение энергетического щита;
- +N к максимуму энергетического щита (флэт);
- +N к максимуму здоровья;
- +N к духу.

### Целевые суффиксы

- +N% к сопротивлению огню / холоду / молнии;
- +N% к сопротивлению хаосу;
- повышение скорости перезарядки энергетического щита;
- +N к интеллекту (если нужен атрибут).

### Логика советов

| Редкость | Ситуация | Совет |
|---|---|---|
| normal | — | Transmutation → Augmentation → смотреть 2 мода |
| magic | 1 хороший мод | Augmentation |
| magic | 2 хороших мода | Regal |
| magic | 1 хороший + мусор | Alchemy / новый base |
| magic | 0 хороших | Alchemy / новый base |
| rare | ≥2 хороших + открытый слот | Exalted Orb в открытый слот |
| rare | ≥2 хороших, слотов нет | Не рероллить |
| rare | 1 хороший, много мусора | Chaos рискованно, лучше новый base |
| rare | 0 хороших | Не тратить валюту |

## Ограничения

- **Без цен**: совет не говорит «выгодно/невыгодно», только «что делать с модами».
- **Без привязки к билду**: универсальные приоритеты; профили билдов — позже.
- **Только чистый ЭЩ**: гибридные базы (броня/ЭЩ, уклонение/ЭЩ) пока не поддерживаются.
- **Нужен advanced-copy** (`Alt+F` / `Ctrl+Alt+C`): без тиров оценка грубее, советник об этом предупреждает.
- Неизвестные моды не угадываются: помечаются «нейтральный/проверь билд».
- Оверлей пока только для чтения; длинную карточку нельзя прокрутить.
