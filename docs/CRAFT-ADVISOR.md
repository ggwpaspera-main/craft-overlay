# Крафт-советник (пробный режим)

M6 заменён: **без trade API и цен**. Задача — по тексту предмета подсказать новичку, что с ним делать дальше.

Текущий скоуп: **все типы экипировки** — доспехи (броня/уклонение/ЭЩ/гибриды), оружие, оффхенд, бижутерия, фляконы, обереги, самоцветы, путевые камни, плитки, реликвии; редкости normal / magic / rare. Оценка не привязана к конкретному билду.

## Откуда правила

- Список целевых модов — из гайда-соседа `poe2-craft-guide/bases.html` («Лучшие статы для волшебного предмета»).
- База модов, тиры и веса — `data/reference/mods-data.json` (54 класса).
- Базы и их свойства — `data/bases.json`.
- Валюта и эффекты — `data/currency.json`.

## Как оценивается предмет

1. Определяется категория/слот: доспех, оружие, оффхенд, бижутерия, флякон и т.д.
2. Явные моды (explicit) раскладываются на префиксы/суффиксы.
3. Каждый мод относится к семейству (жизнь, резист, защита, урон, скорость, крит, +скиллы и т.д.) и сравнивается с целевыми семействами профиля:
   - **хороший** — целевое семейство для этого слота;
   - **нейтральный** — полезно, но не ключевое;
   - **мусор** — слабое семейство (шипы, порог оглушения, снижение требований и т.п.).
4. Считаются открытые слоты (magic: 1P+1S, rare: 3P+3S).
5. Выдаётся совет по редкости.

## Профили

| Тип | Целевые префиксы (кратко) | Целевые суффиксы (кратко) |
|---|---|---|
| Доспехи | % и флэт защиты, жизнь, дух | резисты, хаос-рез, атрибуты; обувь — движение; перчатки — скорость |
| Оружие атаки | % физ/элем урон, флэт урон, жизнь | скорость атаки, крит, +скиллы |
| Оружие кастера | урон от чар, мана, дух, флэт урон | скорость каста, крит, +скиллы |
| Оффхенд | защита/ЭЩ/жизнь, дух | резисты, скорость/крит, +скиллы |
| Бижутерия | жизнь, мана, дух, флэт урон | резисты, хаос-рез, атрибуты, скорость, крит, +скиллы |
| Фляконы | эффект, заряды | длительность, эффект |
| Обереги | эффект, заряды | длительность, эффект |
| Самоцветы | жизнь, урон, флэт урон | резисты, атрибуты, скорость, крит |
| Путевые камни / плитки | количество, редкость, размер групп | эффективность монстров, дроп путевого камня |
| Реликвии | жизнь, защита, дух | резисты, атрибуты, урон |

Для нательных доспехов на ЭЩ есть отдельный подробный профиль: % ЭЩ, флэт ЭЩ, жизнь, дух; резисты, хаос-рез, скорость перезарядки ЭЩ, интеллект.

## Первый ES-профиль

### Стадии предмета

| Редкость | Что оцениваем | Порог ES |
|---|---|---|
| normal | тир базы и ilvl: T1 82+ — хорошо, 79–81 — приемлемо, <79 — плохо | не применяется |
| magic | только аффиксы и их тиры; текущий ES — справочно | не применяется |
| rare | префиксов < 3: ES не сравниваем с порогом; если мусора нет — очернение/Exalt; префиксов 3: проверяем ES | применяется только при 3 префиксах |

Для rare-предмета порог зависит от плана:

| План | ES | Вердикт |
|---|---|---|
| `flat + % + гибрид` или `гибрид ES+жизнь + flat + %` | < 800 | неликвид |
| | 800–899 | пойдёт |
| | ≥ 900 | не трогать |
| `дух + flat + %` | < 650 | неликвид |
| | 650–749 | пойдёт |
| | ≥ 750 | не трогать |

Для magic-предмета с T2 флэт ES и T3 резистом вердикт — «хорошая заготовка под Regal», а не «неликвид»: 253 ES — текущее значение, а не итоговое.

### Base resolver

Если `baseType` пустой (обычно у magic), база ищется внутри полного имени:

`Ослепительное Нечестивое облачение вулкана` → `Нечестивое облачение` = `Vile Robe` (T1).

### Три ES-канала

Важно: это **три отдельных префикса**, они складываются:

1. `flat ES` — `+N к максимуму энергетического щита`;
2. `%ES` — `N% увеличение энергетического щита`;
3. `гибрид` — `flat + %ES`.

Гибрид **не заменяет** чистый flat или чистый %ES при поиске цели: если есть `flat + гибрид`, всё равно нужен чистый `%ES`.

### Планы префиксов

- **Максимум ES:** `flat + %ES + гибрид`, целевой ES **800**.
- **С духом:** `дух + flat + %ES`, гибрид не берём, целевой ES **650** (T1–T2 дух).
- **С гибридом ES+жизнь:** `гибрид + flat + %ES`, цель 800, но остальные два мода должны быть T1–T2; иначе суммарный ES будет ниже.

### Сущности для magic → rare

Для добавления резиста в суффикс подходят только **Большие** сущности сопротивлений:

| Сущность | Мод | Тир |
|---|---|---|
| Большая сущность изоляции | +31–35% огонь | T3 |
| Большая сущность таяния | +31–35% холод | T3 |
| Большая сущность заземления | +31–35% молния | T3 |
| Большая сущность гибели | +16–19% хаос | T3 |

Обычные сущности дают T5, Большая улучшения даёт T4 %ES — по нашим правилам это уже мусор. Совершенные сущности сопротивлений для нательной брони не дают резист.

Логика: если на magic уже есть хороший резист, советник предлагает Большую сущность другого элемента; если резиста нет — первый недостающий элемент. Альтернатива — Regal ради случайного ES-префикса.

### Очернение префикса (Бездна)

Если у редкого ES-предмета меньше 3 префиксов, мусора нет и очернение ещё не использовано:

1. Активировать **Предзнаменование некромантии левши**.
2. Активировать **Предзнаменование отголосков Бездны**.
3. Применить **Сохранившееся ребро** или **Древнее ребро**.
4. В Колодце душ выбрать вариант с префиксом.

Очернение делается **один раз**; дальше — Exalt в открытые префиксы. Очернение может дать любой базовый или очернённый префикс/суффикс.

### Порог мусора по количеству аффиксов

- до 5 аффиксов включительно: **bad ≥ 1** → стоп;
- 6 аффиксов: **bad ≥ 2** → стоп.

### Финализация предмета

Если все 3 префикса и 3 суффикса уже заняты, а ES ниже порога, но предмет ещё не закончен:

- качество < 20% или не вставлены руны → **не junk**, сначала заточить до 20% и вставить 2 железные руны по 18% ES;
- после качества и рун пересчитать ES;
- если после этого ES всё ещё ниже порога — тогда junk.

Для готового предмета с 3 префиксами и 3 суффиксами советник не предлагает Exalt: только качество и руны.

### Прогноз ES при финализации

Если ES ниже порога, советник считает прогноз:

- заточка 0→20% даёт множитель **×1.2**;
- две железные руны по 18% ES дают **+36% increased ES** и складываются с `%ES` модов;
- формула: `ES_прогноз = ES × (1 + %ES + руны) / (1 + %ES + текущие_руны) × (1 + целевое_качество) / (1 + текущее_качество)`.

Пример с предметом 672 ES, `%ES` модов 131:

| Этап | ES | Прирост |
|---|---|---|
| было | 672 | — |
| только заточка 0→20% | 806 | +134 |
| только 2 руны по 18% | 777 | +105 |
| заточка + руны | **932** | **+260** |

Если прогноз после финализации ≤ 800 (или ≤650 с духом) — предмет неликвид. Если > порога — предмет хороший, сначала довести качество/руны.

### Tier-aware моды

- ES-каналы (`flat`, `%ES`, гибрид) T1–T3 — good, **T4+ — плохой**;
- дух T1–T2 — good, T3 — средний, **T4+ — плохой**;
- гибрид ES+жизнь T1–T2 — средний, T3+ — плохой;
- **любой тир чистой жизни** — мусор;
- **любой тир шипов** — мусор.

Точные тиры, уровни и диапазоны ES с poe2db лежат в [data/craft/es-affixes.json](../data/craft/es-affixes.json): flat (11 тиров), %ES (8), гибрид ES (6), гибрид ES+жизнь (6).

Пример: `+20 к максимуму здоровья` T12 — плохой префикс, а не «хороший, потому что жизнь».

### Дополнительно проверяются

- **качество**: если < 20% — сначала заточить, иначе теряется ES;
- **сокеты/руны**: пустые сокеты — проверить, есть ли смысл вставлять;
- **тир базы по NeverSink**: `Vile Robe` — T1, `Ancestral Tiara` — T1, и т.д.

ES берётся из свойства `Энергетический щит` в тексте предмета.

### Фильтр NeverSink как prior

Снимок `data/filter/neversink-0.10.4-3strict.txt` (MIT) разбирается скриптом `npm.cmd run filter:priors` в:

- `data/filter-priors.json` — полный снимок базовых тиров и Show/Hide-правил;
- `data/filter-base-tiers.json` — компактный индекс баз для рантайма.

Hide-правила **не превращаются в чёрный список аффиксов**: скрытие зависит от базы, редкости и контекста. Они сохранены как снимок фильтра; item-level правило «в Hide-тире → плохой предмет» будет отдельным слоем после сопоставления английских имён аффиксов.

## Логика советов

| Редкость | Ситуация | Совет |
|---|---|---|
| normal | — | Сфера превращения → Сфера усиления → смотреть 2 мода |
| magic | 0–1 аффикс | Сфера усиления (Augmentation) — сначала добить второй мод |
| magic | 1 хороший мод | Сфера усиления |
| magic | 2 хороших мода | Сфера царей |
| magic | **любой мусор (bad >= 1)** | **не продолжать: выкинь / Alchemy / новый base** |
| magic | 1 хороший + мусор | Сфера алхимии / новый base |
| magic | 0 хороших | Сфера алхимии / новый base |
| rare | **bad ≥ 1 при ≤5 аффиксах; bad ≥ 2 при 6 аффиксах** | **не продолжать: выкинь / новый base** |
| rare | префиксов < 3, мусора нет | Очернить префикс (ребро + омены), затем Exalt |
| rare | 2+ хороших + открытый слот | Сфера возвышения в открытый слот |
| rare | есть открытый префикс/суффикс, но не хватает целевого семейства | Докрафтить нужное семейство в открытый слот |
| rare | ≥2 хороших, слотов нет | Не рероллить |
| rare | 1 хороший, много мусора | Сфера хаоса рискованна, лучше новый base |
| rare | 0 хороших | Не тратить валюту |

Для путевых камней и плиток советник не предлагает орбы, а оценивает моды для маппинга (количество/редкость/размер групп/опасность).

## Ограничения

- **Без цен**: совет не говорит «выгодно/невыгодно».
- **Без привязки к билду**: универсальные приоритеты; профили билдов — позже.
- Целевые списки для не-ЭЩ слотов — первый универсальный вариант, их надо уточнять по фидбеку.
- Неизвестные моды не угадываются: помечаются «нейтральный/проверь билд».
- Нужен advanced-copy (`Alt+F` / `Ctrl+Alt+C`): без тиров оценка грубее.
- **ES-порог** применяется к body armour и берёт значение из свойства предмета; если качество/руны в тексте не видны, советник об этом предупреждает.
- **Тировые пороги** (T1–T3 good, T4+ плохой) — для ES и целевых модов; для остальных семейств пороги ещё уточняются.
- **NeverSink 0.10.4** — снимок; тиры баз могут устареть после патча/лиги.
- Hide-правила сохранены, но пока не используются как вердикт по предмету: для этого нужно сопоставить английские имена аффиксов с нашей моделью.
- Камни умений, валюта и квестовые предметы не оцениваются.
