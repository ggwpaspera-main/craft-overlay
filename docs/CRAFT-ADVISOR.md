# Крафт-советник (пробный режим)

M6 заменён: **без trade API и цен**. Задача — по тексту предмета подсказать новичку, что с ним делать дальше.

Текущий скоуп: **все типы экипировки** — доспехи (броня/уклонение/ЭЩ/гибриды), оружие, оффхенд, бижутерия, фляконы, обереги, самоцветы, путевые камни, плитки, реликвии; редкости normal / magic / rare. Оценка не привязана к конкретному билду.

## Откуда правила

- Список целевых модов — из гайда-соседа `poe2-craft-guide/bases.html` («Лучшие статы для волшебного предмета»).
- База модов, тиры и веса — `data/reference/mods-data.json` (54 класса).
- Базы и их свойства — `data/bases.json`.
- Валюта и эффекты — `data/currency.json`.

## Как оценивается предмет

1. Определяется категория/слот: доспех, оружие, оффхенд, бижутерия, флякон и т.д.
2. Явные моды (explicit) раскладываются на префиксы/суффиксы.
3. Каждый мод относится к семейству (жизнь, резист, защита, урон, скорость, крит, +скиллы и т.д.) и сравнивается с целевыми семействами профиля:
   - **хороший** — целевое семейство для этого слота;
   - **нейтральный** — полезно, но не ключевое;
   - **мусор** — слабое семейство (шипы, порог оглушения, снижение требований и т.п.).
4. Считаются открытые слоты (magic: 1P+1S, rare: 3P+3S).
5. Выдаётся совет по редкости.

## Профили

| Тип | Целевые префиксы (кратко) | Целевые суффиксы (кратко) |
|---|---|---|
| Доспехи | % и флэт защиты, жизнь, дух | резисты, хаос-рез, атрибуты; обувь — движение; перчатки — скорость |
| Оружие атаки | % физ/элем урон, флэт урон, жизнь | скорость атаки, крит, +скиллы |
| Оружие кастера | урон от чар, мана, дух, флэт урон | скорость каста, крит, +скиллы |
| Оффхенд | защита/ЭЩ/жизнь, дух | резисты, скорость/крит, +скиллы |
| Бижутерия | жизнь, мана, дух, флэт урон | резисты, хаос-рез, атрибуты, скорость, крит, +скиллы |
| Фляконы | эффект, заряды | длительность, эффект |
| Обереги | эффект, заряды | длительность, эффект |
| Самоцветы | жизнь, урон, флэт урон | резисты, атрибуты, скорость, крит |
| Путевые камни / плитки | количество, редкость, размер групп | эффективность монстров, дроп путевого камня |
| Реликвии | жизнь, защита, дух | резисты, атрибуты, урон |

Для нательных доспехов на ЭЩ есть отдельный подробный профиль: % ЭЩ, флэт ЭЩ, жизнь, дух; резисты, хаос-рез, скорость перезарядки ЭЩ, интеллект.

## Логика советов

| Редкость | Ситуация | Совет |
|---|---|---|
| normal | — | Сфера превращения → Сфера усиления → смотреть 2 мода |
| magic | 1 хороший мод | Сфера усиления |
| magic | 2 хороших мода | Сфера царей |
| magic | 1 хороший + мусор | Сфера алхимии / новый base |
| magic | 0 хороших | Сфера алхимии / новый base |
| rare | ≥2 хороших + открытый слот | Сфера возвышения в открытый слот |
| rare | ≥2 хороших, слотов нет | Не рероллить |
| rare | 1 хороший, много мусора | Сфера хаоса рискованна, лучше новый base |
| rare | 0 хороших | Не тратить валюту |

Для путевых камней и плиток советник не предлагает орбы, а оценивает моды для маппинга (количество/редкость/размер групп/опасность).

## Ограничения

- **Без цен**: совет не говорит «выгодно/невыгодно».
- **Без привязки к билду**: универсальные приоритеты; профили билдов — позже.
- Целевые списки для не-ЭЩ слотов — первый универсальный вариант, их надо уточнять по фидбеку.
- Неизвестные моды не угадываются: помечаются «нейтральный/проверь билд».
- Нужен advanced-copy (`Alt+F` / `Ctrl+Alt+C`): без тиров оценка грубее.
- Камни умений, валюта и квестовые предметы не оцениваются.
